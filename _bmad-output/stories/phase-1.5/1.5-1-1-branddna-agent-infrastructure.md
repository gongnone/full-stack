## User Story

**As a** developer,
**I want** the BrandDNAAgent Durable Object to be scaffolded with WebSocket support,
**So that** all subsequent stories have a foundation to build upon.

## Context

This is the foundational infrastructure story for Phase 1.5. The BrandDNAAgent extends Cloudflare's Agent class and provides per-client stateful conversation with SQLite persistence.

## Acceptance Criteria

### AC1: Durable Object Scaffold
- [x] Create BrandDNAAgent class extending Cloudflare `Agent`
- [x] Initialize with `this.sql` for SQLite state storage
- [x] Support WebSocket connections via `onConnect`/`onMessage`
- [x] Broadcast structured responses with `component.type` and `props`

### AC2: WebSocket Welcome
- [x] On client connect, send welcome message: `{ component: { type: 'TextMessage', props: { content: '...' } } }`
- [x] Welcome message includes session state if resuming

### AC3: Session Reconnection
- [x] If WebSocket drops and client reconnects within 30 minutes
- [x] Restore session state from `this.sql`
- [x] Resume conversation exactly where it left off
- [x] No user input is lost

### AC4: Rate Limiting
- [x] Rate-limit connections exceeding 30 messages per minute
- [x] Return error: `{ error: 'rate_limited', retry_after: 60 }`
- [x] Log excessive requests for abuse detection

### AC5: Hibernation Handling
- [x] Before DO hibernation, persist all session state to `this.sql`
- [x] State is fully recoverable on next wake
- [x] No data is lost during hibernation cycles

```typescript
    // Restore or create session

  }

  async onMessage(ws: WebSocket, message: string) {
    // Rate limiting check
    // Process message
    // Broadcast structured response
  }
}
```

### Database Schema
```sql
-- this.sql schema
CREATE TABLE IF NOT EXISTS session_state (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL,
  updated_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS conversation_history (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  role TEXT NOT NULL,  -- 'user' | 'agent'
  content TEXT NOT NULL,
  component_type TEXT,
  created_at INTEGER NOT NULL
);
```
