**Created:** 2025-12-30

## User Story

**As a** user,
**I want** each spoke to be adapted to its target platform's format,
**So that** content feels native to each platform.

## Acceptance Criteria

### AC1: Twitter/X
- [ ] 280 character limit
- [ ] Punchy, contrarian hooks
- [ ] 0-2 relevant hashtags

### AC2: LinkedIn
- [ ] Professional but authentic tone
- [ ] Up to 3000 characters
- [ ] Strong hook line opener

### AC3: TikTok/Reels
- [ ] Hook in first 3 seconds
- [ ] Clear middle section
- [ ] Soft call-to-action

### AC4: Carousel
- [ ] 10-slide outline with progressive reveal structure
