# Story 1.5-1-2: Voice Recording Component (Mobile)

**Epic:** 1.5-1 - BrandDNA Agent - Voice Capture
**Priority:** P0
**Status:** review
**Effort:** 6-8 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to record a voice note describing my brand on my mobile device,
**So that** I can articulate my brand personality naturally.

## Context

Voice capture is the primary input for Brand DNA. Mobile-first design is mandatory. Must handle iOS Safari MediaRecorder quirks (drops audio after ~1 minute).

## Acceptance Criteria

### AC1: Voice Recorder UI
- [x] VoiceRecorder component appears with timer (max 300 seconds / 5 minutes)
- [x] Uses MediaRecorder API (NFR-1.5-M2)
- [x] Visual waveform indicator during recording
- [x] Large touch targets (44px minimum)

### AC2: Multi-Segment Recording
- [x] After recording, show "Add Another Recording" option
- [x] All segments analyzed together for richer Brand DNA
- [x] Clear indication of total recorded time

### AC3: Stop and Preview
- [x] Auto-stop at 120 seconds (or user tap)
- [x] Preview audio before submitting
- [x] Re-record option discards previous recording

### AC4: iOS Safari Chunking
- [x] For iOS Safari, use 30-second chunked recording
- [x] Segments stitched server-side transparently
- [x] No interruption visible to user

### AC5: Resumable Upload
- [x] For files > 1MB, use resumable upload (tus protocol)
- [x] Show upload progress percentage
- [x] Resume from last chunk on connection drop

### AC6: Fallback for Unsupported Browsers
- [x] If MediaRecorder unsupported, show helpful message
- [x] Offer alternative: upload pre-recorded audio file
