## User Story

**As a** user,
**I want** generated spokes to be stored and linked to my Hub,
**So that** I can review and manage them.

## Acceptance Criteria

### AC1: Database Storage
- [ ] Create `spokes` record:
  - `hub_id`, `client_id` foreign keys
  - `platform` (twitter, linkedin, tiktok, carousel)
  - `content` (text or JSON)
  - `status` = "pending_review"

### AC2: Completion Notification
- [ ] Update `hubs.status` = "generated"
- [ ] Notify: "25 spokes ready for review"
