# Story 1.5-1-3: Voice Note Transcription

**Epic:** 1.5-1 - BrandDNA Agent - Voice Capture
**Priority:** P0
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

## User Story

**As a** user,
**I want** my voice note to be transcribed automatically,
**So that** I can review what I said and the system can analyze it.

## Context

Uses Workers AI Whisper for transcription. Must complete in < 30 seconds (NFR-1.5-P1). Server-side validation prevents malicious uploads.

## Acceptance Criteria

### AC1: Server-Side Validation
- [x] Validate file type via magic bytes (not just extension)
- [x] File size < 10MB
- [x] Duration < 5 minutes (from audio metadata)
- [x] Reject invalid files with clear error message
- [x] Log rejections for security monitoring

### AC2: R2 Storage
- [x] Upload to R2: `/voice-notes/{client_id}/{session_id}.webm`
- [x] Encrypted at rest (AES-256, NFR-1.5-D1)
- [x] Store R2 key in `voice_recordings` table

### AC3: Whisper Transcription
- [x] Send audio to Workers AI Whisper
- [x] Processing completes in < 30 seconds (NFR-1.5-P1)
- [x] Store transcription in `voice_recordings.transcription`

### AC4: Progress Indication
- [x] During transcription, show ResearchStatus component
- [x] Message: "Transcribing your voice..."
- [x] Progress updates via WebSocket

### AC5: Transcription Display
- [x] Show transcription text for user review
- [x] Allow user to see and verify accuracy

async function validateAudioFile(r2Object: R2Object): Promise<boolean> {
  const header = await r2Object.slice(0, 12).arrayBuffer();
  const magicBytes = new Uint8Array(header);

  // Check for audio magic bytes (webm, mp3, wav, etc.)
  const isValidAudio = checkAudioMagicBytes(magicBytes);
  const size = r2Object.size;
  const duration = await getAudioDuration(r2Object);

  return isValidAudio && size < 10_000_000 && duration < 300;
}
