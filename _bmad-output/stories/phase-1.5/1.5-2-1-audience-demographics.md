# Story 1.5-2-1: Audience Demographics Questionnaire

**Epic:** 1.5-2 - BrandDNA Agent - Audience & Strategy Discovery
**Priority:** P0
**Status:** ready-for-dev
**Effort:** 3-4 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** the agent to ask structured questions about my target audience demographics,
**So that** I can define who I'm trying to reach.

## Acceptance Criteria

### AC1: Conversational Flow
- [ ] ONE question at a time via ButtonChoice (not multi-field form)
- [ ] Mobile-first with 44px touch targets

### AC2: Age Range Question
- [ ] ButtonChoice: "18-24", "25-34", "35-44", "45-54", "55+"
- [ ] Immediate acknowledgment and next question

### AC3: Industry Question
- [ ] Quick-tap chips (multi-select allowed)
- [ ] Large enough for mobile touch

### AC4: Summary and Confirmation
- [ ] TextMessage with inferred demographics
- [ ] "Looks good" or "Let me adjust"
- [ ] Store in `audience_personas.demographics` JSON field

## War Room Finding

Forms are friction on mobile - use conversational ButtonChoice.
