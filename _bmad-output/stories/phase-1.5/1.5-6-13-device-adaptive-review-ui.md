# Story 1.5-6-13: Device-Adaptive Review UI

**Epic:** 1.5-6 - Mobile Review & Native Publish Flow
**Priority:** P1
**Status:** review
**Effort:** 6-8 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** the review interface to adapt to my device,
**So that** I get the optimal experience on phone, tablet, or desktop.

## Acceptance Criteria

### AC1: Phone (< 768px)
- [ ] Swipe-card interface
- [ ] Full-width cards with 44px+ touch targets
- [ ] One spoke visible with stack preview

### AC2: Tablet (768-1024px)
- [ ] 2-column grid of spoke cards
- [ ] Approve/reject buttons (no swipe required)
- [ ] Tap to expand details

### AC3: Desktop (> 1024px)
- [ ] 3-4 column grid
- [ ] Hover states show content preview
- [ ] Keyboard shortcuts: J/K navigate, A approve, R reject, L love
- [ ] Prominent bulk select mode

### AC4: Cross-Device Sync
- [ ] Place in queue preserved
- [ ] UI adapts on device switch
- [ ] In-progress review synced

## Comparative Analysis

Tinder-style swipe for mobile, Kanban grid for desktop.
