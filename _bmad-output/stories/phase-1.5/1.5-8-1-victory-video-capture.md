# Story 1.5-8-1: Victory Video Capture (Unified)

**Epic:** 1.5-8 - Testimonial Collection
**Priority:** P0
**Status:** review
**Effort:** 6-8 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to optionally capture a "Victory Video" at milestone moments,
**So that** I can preserve my excitement without friction.

## Acceptance Criteria

### AC1: Trigger Points
- [ ] BrandDNA completion: "Capture this moment?"
- [ ] First batch approval: Same prompt
- [ ] "Skip" equally prominent as "Record"

### AC2: Recording Flow
- [ ] Front-facing camera default
- [ ] 30-second limit (not 5 minutes)
- [ ] iOS Safari 15+ and Android Chrome 90+ support
- [ ] Countdown timer

### AC3: Preview
- [ ] "Save" or "Re-record" only (no trim/edit)

### AC4: Upload
- [ ] Client-side compression (< 5MB for 30s)
- [ ] Resumable upload
- [ ] Progress indicator

### AC5: Storage
- [ ] R2: `/victory-videos/{client_id}/{date}.webm`
- [ ] `videos` table: type="victory", is_public=false

### AC6: Server Validation
- [ ] Magic bytes, size < 10MB, duration < 60s

### AC7: Skip Behavior
- [ ] Instant dismiss, no guilt-trip
- [ ] No follow-up for 7 days

### AC8: View Later
- [ ] Settings > My Milestones
- [ ] Timeline of Victory Videos
- [ ] Can play or delete

## Occam's Razor Note

Four separate video stories consolidated into one unified flow.
