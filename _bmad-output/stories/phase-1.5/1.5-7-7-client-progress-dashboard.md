# Story 1.5-7-7: Client Progress Dashboard

**Epic:** 1.5-7 - Agency Owner Dashboard
**Priority:** P1
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As an** agency owner,
**I want** to see a dashboard showing all clients' real-time BrandDNA progress,
**So that** I can proactively follow up with stuck clients.

## Acceptance Criteria

### AC1: Progress Overview
- [ ] Clients Not Started (count + list)
- [ ] Clients In Progress (count + % complete)
- [ ] Clients Complete (count + list)

### AC2: Needs Nudge Flag
- [ ] > 7 days in progress: "Needs Nudge" indicator
- [ ] Send reminder from dashboard

### AC3: Detailed Progress
- [ ] Phases with timestamps
- [ ] Time spent on each phase

## Focus Group Finding

Sarah Park frustrated when agency doesn't follow up - agency needs visibility.
