# Story 1.5-9-2: Consent Version Tracking

**Epic:** 1.5-9 - Compliance & Data Privacy
**Priority:** P1
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As the** system,
**I want** to track which version of terms/privacy policy users consented to,
**So that** we have audit trail for compliance.

## Acceptance Criteria

### AC1: Consent Logging
- [ ] `consent_log` table:
  - user_id, consent_type, version
  - country_code (NOT raw IP)
  - user_agent (browser family only)
  - consented_at

### AC2: Terms Update Prompt
- [ ] On new terms version, prompt returning users
- [ ] New consent record created

### AC3: Testimonial Permission Logging
- [ ] Log explicit consent for testimonial public use
- [ ] Satisfies GDPR Article 7

### AC4: Audit Query
- [ ] Complete consent history per user

## Security Note

Security Audit: IP addresses are PII under GDPR - log only country/region.

## Focus Group Finding

David Chen - Must track consent versions for audit defense.
