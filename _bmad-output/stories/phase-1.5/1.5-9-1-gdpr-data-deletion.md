# Story 1.5-9-1: Data Deletion Request (GDPR Right to Erasure)

**Epic:** 1.5-9 - Compliance & Data Privacy
**Priority:** P1
**Status:** review
**Effort:** 6-8 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to request complete deletion of my data,
**So that** I can exercise my GDPR "right to be forgotten".

## Acceptance Criteria

### AC1: Deletion Request UI
- [ ] Settings > Privacy > "Request Data Deletion"
- [ ] Explain what will be deleted and permanence

### AC2: Confirmation
- [ ] Password verification required
- [ ] Create pending deletion request
- [ ] Email confirmation with request ID

### AC3: Deletion Job
- [ ] Queue via Cloudflare Queue
- [ ] Delete R2 objects, D1 records, Vectorize embeddings
- [ ] Soft delete account for audit trail

### AC4: Deletion Certificate
- [ ] Generate PDF with request ID, categories deleted, timestamp
- [ ] Email to user
- [ ] Retain 7 years for legal compliance

### AC5: Agency Client Grace Period
- [ ] Notify agency owner
- [ ] 7-day grace period for data export

## Security Note

Security Audit: Deletion certificate provides proof for audit defense.

## Focus Group Finding

David Chen (Compliance) - GDPR Article 17 requires right to erasure.
