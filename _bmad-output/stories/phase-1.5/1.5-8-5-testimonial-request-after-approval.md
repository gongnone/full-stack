# Story 1.5-8-5: Testimonial Request After Batch Approval

**Epic:** 1.5-8 - Testimonial Collection
**Priority:** P0
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** the agent to ask for a testimonial when I'm feeling positive,
**So that** my enthusiasm is captured at the optimal moment.

## Acceptance Criteria

### AC1: Sentiment Check First
- [ ] After approving 10+ spokes, ask "How are you feeling?"
- [ ] Options: "Excited to post!", "They're solid", "Need some work"

### AC2: Positive Sentiment
- [ ] If "Excited": Prompt for testimonial
- [ ] Feel natural, not interruption

### AC3: Lukewarm/Negative Sentiment
- [ ] Defer testimonial request
- [ ] "We'll ask again when you're feeling great"
- [ ] Set `testimonial_ask_deferred_until`

### AC4: Transparency
- [ ] Request is respectful
- [ ] Explains how testimonials help others

## SCAMPER Note

Combine: Merge sentiment check + testimonial request - only ask when genuinely happy.
