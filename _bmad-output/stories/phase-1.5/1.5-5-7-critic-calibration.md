## User Story

**As the** system,
**I want** to use user-approved spokes as positive training examples,
**So that** G4 scoring becomes personalized over time.

## Acceptance Criteria

### AC1: Approval Storage
- [ ] Add approved spoke to Vectorize namespace
- [ ] Metadata: `{ type: 'approved_example', client_id, spoke_id }`

### AC2: Personalized G4 Scoring
- [ ] Retrieve approved examples for client
- [ ] Compare new spoke voice similarity
- [ ] Similarity score influences G4 decision

### AC3: Bootstrap Mode
- [ ] < 10 approvals: Use generic brand voice matching
- [ ] Note: "G4 accuracy improves after 10+ approvals"

### AC4: Full Calibration
- [ ] 10+ approvals: Use personalized calibration
- [ ] ~20% accuracy improvement expected

## Reverse Engineering Finding

Without calibration, G4 is generic - personalization requires learning from approvals.
