# Story 1.5-10-3: Per-Client Rate Limiting

**Epic:** 1.5-10 - Operations & Resilience
**Priority:** P2
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As the** system,
**I want** per-client rate limits on resource-intensive operations,
**So that** one client can't overwhelm the system.

## Acceptance Criteria

### AC1: Hub Creation Limit
- [ ] 10 Hubs per day per client
- [ ] "Daily Hub limit reached. Try again tomorrow."
- [ ] Sliding window in D1

### AC2: Generation Queue
- [ ] > 5 active jobs: queue new jobs
- [ ] "Generation queued - 2 jobs ahead of you"

### AC3: API Rate Limit
- [ ] 100 requests/minute per client
- [ ] 429 response with reset time header
- [ ] Log excessive requests

### AC4: Agency Isolation
- [ ] Limits per-client, not per-agency
- [ ] One client's abuse doesn't affect others

## Red Team Finding

Hub creation flooding could overwhelm system - need per-client limits.
