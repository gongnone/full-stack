## User Story

**As a** user,
**I want** the system to extract my tone, vocabulary, and personality markers from my transcription,
**So that** my Brand DNA begins to form.

## Acceptance Criteria

### AC1: Input Sanitization (Security Critical)
- [x] User content delimited with `<user_content>` tags
- [x] System prompts isolated and immutable
- [x] Known prompt injection patterns escaped or flagged
- [x] Sanitized transcription passed to Workers AI

### AC2: Personality Extraction
- [x] Extract primary tone (e.g., "Direct and confident")
- [x] Extract key vocabulary patterns (signature phrases)
- [x] Extract personality markers (e.g., "Anti-corporate")

### AC3: Results Display
- [x] Show TextMessage with detected characteristics
- [x] Store in `brand_dna_sessions.voice_analysis` JSON field

## Technical Implementation

```typescript
// Prompt sanitization
const sanitizedInput = `<user_content>${escapePromptInjection(transcription)}</user_content>`;

// Workers AI extraction
const analysis = await AI.run('@cf/meta/llama-2-7b-chat', {
  prompt: `${SYSTEM_PROMPT}\n\nAnalyze this voice transcription:\n${sanitizedInput}`,
  schema: {
    tone: 'string',
    vocabulary: 'array',
    personality_markers: 'array'
  }
});
```
