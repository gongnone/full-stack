# Story 1.5-1-7: Text-Only BrandDNA Path

**Epic:** 1.5-1 - BrandDNA Agent - Voice Capture

**Status:** review

**Created:** 2025-12-30

## User Story

**As a** user who cannot or prefers not to record voice,
**I want** to complete BrandDNA using text input only,
**So that** I can still benefit from the system without voice recording.

## Acceptance Criteria

### AC1: Path Selection
- [x] At voice capture step, show ButtonChoice: "Record Voice" or "Type Instead"

### AC2: Text Input
- [x] Large text area with prompt: "Describe your brand in your own words..."
- [x] Minimum 200 characters required
- [x] Maximum 5000 characters allowed

### AC3: Text Analysis
- [x] Brand personality extraction runs on text (reuse Story 1.4)
- [x] Analysis quality comparable to voice analysis
- [x] Continue to Epic 2 without voice recording

### AC4: Add More Later
- [x] Can add text samples or switch to voice recording later
- [x] All inputs combined for richer Brand DNA

## SCAMPER Note

Substitute: Voice recording substituted with text for accessibility and preference.
