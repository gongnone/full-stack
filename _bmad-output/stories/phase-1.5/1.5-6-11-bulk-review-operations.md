# Story 1.5-6-11: Bulk Review Operations

**Epic:** 1.5-6 - Mobile Review & Native Publish Flow
**Priority:** P1
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As a** user with many spokes to review,
**I want** to approve or reject multiple spokes at once,
**So that** I can work efficiently through large queues.

## Acceptance Criteria

### AC1: Select Mode
- [ ] "Select Mode" shows checkboxes on cards
- [ ] Tap cards to select/deselect

### AC2: Bulk Actions
- [ ] "Approve Selected (12)" and "Reject Selected (12)" buttons
- [ ] Color-coded (green/red)

### AC3: Bulk Execution
- [ ] Single API call for batch
- [ ] Toast: "12 spokes approved"
- [ ] Exit select mode automatically

### AC4: Smart Select
- [ ] "Select All LinkedIn" or "Select All Score > 80"
- [ ] Auto-select matching spokes

### AC5: Efficiency Gain
- [ ] 50+ spokes: ~2 min instead of ~8 min

## Reverse Engineering Finding

Reviewing 25+ spokes one-by-one is tedious - bulk operations essential.
