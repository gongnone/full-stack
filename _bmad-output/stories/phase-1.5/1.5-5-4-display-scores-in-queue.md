# Story 1.5-5-4: Display Scores in Review Queue

**Epic:** 1.5-5 - Critic Agent - Quality Scoring (Lite)
**Priority:** P0
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to see quality scores displayed alongside each spoke,
**So that** I can prioritize my review without cognitive overload.

## Acceptance Criteria

### AC1: Default View (Composite Score)
- [ ] Single large number (weighted: G2 x 0.5 + G4_pass x 25 + G5_pass x 25)
- [ ] Color coding (green > 70, yellow 50-70, red < 50)
- [ ] Status: "Ready to post" or "Needs attention"

### AC2: Detail View
- [ ] On tap, show G2 score with feedback
- [ ] G4 badge (checkmark or X) with feedback
- [ ] G5 badge (checkmark or X) with feedback

### AC3: Settings Toggle
- [ ] "Show All Scores" to always show detailed view
- [ ] Save preference for future sessions

## Occam's Razor Note

One number is easier to scan than three - composite score as default.
