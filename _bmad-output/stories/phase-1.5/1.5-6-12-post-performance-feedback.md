# Story 1.5-6-12: Post-Performance Feedback (Manual)

**Epic:** 1.5-6 - Mobile Review & Native Publish Flow
**Priority:** P1
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to manually record how my posted content performed,
**So that** I can learn which spokes resonate with my audience.

## Acceptance Criteria

### AC1: Performance Prompt
- [ ] 24+ hours after hand-off, show "How did it perform?"
- [ ] Options: Great, Good, Okay, Poor (1-4 scale)

### AC2: Rating Storage
- [ ] Store `spokes.performance_rating`
- [ ] Optional note: "Got 50 likes, 10 comments"
- [ ] Link to Hub for pattern analysis

### AC3: Analytics (10+ ratings)
- [ ] "Top-performing spoke types: LinkedIn text posts"
- [ ] "Consider more: Contrarian hooks"

### AC4: Cross-Hub Analytics
- [ ] Performance trends by platform, content type, pillar
- [ ] Critic Agent can improve G2 scoring

## Pre-mortem Finding

Users had no way to see what worked - no feedback loop to improve.
