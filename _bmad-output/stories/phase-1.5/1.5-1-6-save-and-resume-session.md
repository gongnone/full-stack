## User Story

**As a** user,
**I want** to save my BrandDNA session progress and resume later,
**So that** I don't lose work if I need to step away or switch devices.

## Acceptance Criteria

### AC1: Auto-Save
- [x] Session state automatically saved to `this.sql`
- [x] No explicit "save" action required
- [x] Saves on browser close or app switch

### AC2: Resume Banner
- [x] On return, show banner: "Continue your Brand Discovery? You're 45% complete."
- [x] "Continue" resumes exactly where left off
- [x] "Start Over" begins fresh session

### AC3: Context Restoration
- [x] All previous answers and recordings restored
- [x] Agent summarizes: "Welcome back! Last time we covered your voice analysis."
- [x] Conversation history visible for context

### AC4: Session Expiry
- [x] Sessions > 30 days show: "Your previous session expired. Start fresh?"
- [x] Expired data archived (not deleted) for potential recovery

### AC5: Cross-Device Sync
- [x] Session state synchronized across devices
- [x] Continue seamlessly on mobile or desktop

## Pre-mortem Finding

40% of users abandoned BrandDNA because they couldn't save and continue later.

### Implementation Notes
- `listIncompleteSessions` - Returns active sessions with progress (0-100%)
- `getSessionWithContext` - Full context restoration with welcome message
- `archiveExpiredSession` - Archives (doesn't delete) expired sessions
- `startFreshSession` - Creates new session, optionally archives previous
- Progress calculation: recording(25%) + transcription(25%) + analysis(25%) + duration(25%)
- Expiry: Sessions >30 days marked as expired
- Cross-device sync via D1 database (sessions stored server-side)
