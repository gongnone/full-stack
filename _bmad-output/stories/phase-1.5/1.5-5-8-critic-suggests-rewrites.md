# Story 1.5-5-8: Critic Suggests Specific Rewrites

**Epic:** 1.5-5 - Critic Agent - Quality Scoring (Lite)
**Priority:** P1
**Status:** review
**Effort:** 6-8 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** the Critic to suggest specific rewrites for low-scoring spokes,
**So that** I know exactly how to improve weak content.

## Acceptance Criteria

### AC1: G2 Rewrite Suggestions
- [ ] 2-3 specific hook rewrites:
  - "Try: 'Most people get this completely wrong...'"
  - "Consider: 'What if everything you know about X is backwards?'"

### AC2: G4 Rewrite Suggestions
- [ ] Phrases to add/remove:
  - "Add your signature phrase: '[phrase]'"
  - "Tone too formal - consider: '[casual rewrite]'"

### AC3: G5 Fixes
- [ ] Automatic fixes:
  - "Tweet is 312 chars - here's 280-char version: '[trimmed]'"

### AC4: Apply Suggestion
- [ ] "Apply Suggestion" updates spoke content
- [ ] Re-score automatically
- [ ] Save original in `spokes.revision_history`

### AC5: Manual Edit
- [ ] "Edit Manually" shows edit mode with suggestions as reference

## SCAMPER Note

Modify: Transform feedback from "what's wrong" to "here's how to fix it".
