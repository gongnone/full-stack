# Story 1.5-1-8: Express BrandDNA (60-Second Path)

**Epic:** 1.5-1 - BrandDNA Agent - Voice Capture
**Priority:** P1
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As a** busy user,
**I want** to complete a minimal BrandDNA in under 60 seconds,
**So that** I can start generating content immediately without a long onboarding.

## Acceptance Criteria

### AC1: Path Selection
- [x] Welcome shows: "Full Discovery (~15 min)" or "Express Setup (~60 sec)"

### AC2: Express Flow (3 Questions)
1. "In one sentence, what do you do?" (text input)
2. "Pick 3 words that describe your tone" (ButtonChoice)
3. "Which platform is your priority?" (ButtonChoice)

### AC3: Starter Brand DNA
- [x] Generate basic tone profile from selected words
- [x] Platform focus for spoke generation
- [x] Default audience persona (refinable later)
- [x] Brand DNA Strength shows "Starter - 40%"

### AC4: Upgrade Path
- [x] Generation works with starter profile
- [x] Quality may be lower (G4: "Limited brand data")
- [x] "Upgrade" to full BrandDNA available anytime

## First Principles Note

Core need is "get content out" - minimize time-to-first-spoke.
