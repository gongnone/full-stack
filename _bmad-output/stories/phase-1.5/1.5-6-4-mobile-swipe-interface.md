# Story 1.5-6-4: Mobile Swipe Interface

**Epic:** 1.5-6 - Mobile Review & Native Publish Flow
**Priority:** P0
**Status:** review
**Effort:** 6-8 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to swipe to approve or reject spokes with nuance,
**So that** I can review quickly while capturing enthusiasm level.

## Acceptance Criteria

### AC1: Swipe Right (Approve)
- [ ] > 150px swipe: Green flash, status = "approved"

### AC2: Super Swipe (Love)
- [ ] > 250px swipe: Gold star effect, status = "loved"
- [ ] `spokes.reaction` = "love"
- [ ] Toast: "Loved it!"

### AC3: Swipe Left (Reject)
- [ ] > 150px swipe: Red flash, status = "rejected"

### AC4: Animation Quality
- [ ] 60fps animations (NFR-1.5-M5)
- [ ] Touch targets 44px minimum (NFR-1.5-M4)

### AC5: Accidental Swipe Prevention
- [ ] 200ms hold before swipe registers
- [ ] Accidental swipes from scroll ignored

### AC6: Undo Toast
- [ ] 5-second undo window
- [ ] "Undo" reverses action

## Lessons Learned

"Love it" vs "Approve" captures enthusiasm gradient - helps Critic learn.

## War Room Finding

100px threshold too sensitive - add debounce and undo.
