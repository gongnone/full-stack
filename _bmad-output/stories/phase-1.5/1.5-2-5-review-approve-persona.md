## User Story

**As a** user,
**I want** to review and approve (or edit) my generated persona,
**So that** I have confidence the system understands my audience.

## Acceptance Criteria

### AC1: Action Buttons
- [ ] "Approve", "Edit", "Regenerate" buttons on PersonaCard

### AC2: Edit Mode
- [ ] Can modify any field in the persona
- [ ] Changes saved to database

### AC3: Regenerate
- [ ] Generates new persona with different emphasis
- [ ] Can compare and choose

### AC4: Approval
- [ ] Set `audience_personas.status` = "approved"
- [ ] Proceed to competitor analysis
