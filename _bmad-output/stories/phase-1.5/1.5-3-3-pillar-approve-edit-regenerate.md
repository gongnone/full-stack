## User Story

**As a** user,
**I want** to approve, edit, or regenerate individual pillars,
**So that** I have full control over my content strategy.

## Acceptance Criteria

### AC1: Approve
- [ ] Mark pillar approved (green checkmark)
- [ ] Set `content_pillars.status` = "approved"

### AC2: Edit
- [ ] Modify pillar title and description
- [ ] Save changes immediately

### AC3: Regenerate
- [ ] Generate new pillar with different angle
- [ ] Compare old vs new before deciding
- [ ] Incorporate feedback (e.g., "more contrarian")

### AC4: Bulk Approve
- [ ] "These all look good" button to approve all in one action
- [ ] Proceed to Story 3.5 without individual taps

## Occam's Razor Note

Don't force 5 taps when one tap would do.
