# Story 1.5-3-7: Export Brand DNA Report as PDF

**Epic:** 1.5-3 - BrandDNA Agent - Pillars & Report
**Priority:** P1
**Status:** ready-for-dev
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to export my Brand DNA Report as a PDF,
**So that** I can share it with my team or save for reference.

## Acceptance Criteria

### AC1: Export Button
- [ ] "Export PDF" button triggers server-side generation
- [ ] Loading indicator: "Generating your report..."

### AC2: PDF Contents
- [ ] Professional formatting
- [ ] All report sections
- [ ] Brand DNA Strength score
- [ ] Date generated

### AC3: Storage and Download
- [ ] Store in R2: `/reports/{client_id}/brand-dna-{date}.pdf`
- [ ] Provide download link (not client-side generation)
- [ ] Works reliably on mobile browsers

## War Room Finding

Client-side PDF generation is slow and memory-intensive on mobile - use server-side.
