# Story 1.5-9-4: GDPR Data Export (Right to Portability)

**Epic:** 1.5-9 - Compliance & Data Privacy
**Priority:** P1
**Status:** review
**Effort:** 6-8 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to export all my data in a portable format,
**So that** I can exercise my GDPR "right to data portability".

## Acceptance Criteria

### AC1: Export Request
- [ ] Settings > Privacy > "Export My Data"
- [ ] Explain ZIP file generation

### AC2: Export Contents
- [ ] Brand DNA Report (JSON + PDF)
- [ ] Voice recordings (audio files)
- [ ] Audience personas (JSON)
- [ ] Content pillars (JSON)
- [ ] Generated spokes (JSON)
- [ ] Testimonials (video files)
- [ ] Consent history (JSON)

### AC3: Delivery
- [ ] Email with secure download link (24h expiry)
- [ ] Clear folder hierarchy
- [ ] Standard JSON formats

### AC4: Agency Client Scope
- [ ] Only user's data exported
- [ ] Agency relationship metadata included

## Round Table Finding

Legal Leo - GDPR Article 20 requires data portability.
