# Story 1.5-7-5: Export Testimonials

**Epic:** 1.5-7 - Agency Owner Dashboard
**Priority:** P1
**Status:** review
**Effort:** 3-4 hours
**Created:** 2025-12-30

---

## User Story

**As an** agency owner,
**I want** to download/export testimonial videos,
**So that** I can use them in marketing materials.

## Acceptance Criteria

### AC1: Single Download
- [ ] Video downloads from R2 signed URL

### AC2: Bulk Export
- [ ] Select multiple, generate ZIP file

### AC3: Audit Logging
- [ ] Log export: agency_owner_id, testimonial_ids, timestamp, country
- [ ] Retain 2 years for audit

## Security Note

Red Team: Testimonial export abuse must be auditable.
