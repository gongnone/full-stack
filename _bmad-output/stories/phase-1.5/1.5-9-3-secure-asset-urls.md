# Story 1.5-9-3: Secure Asset URLs

**Epic:** 1.5-9 - Compliance & Data Privacy
**Priority:** P0
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As the** system,
**I want** all R2 asset URLs to be time-limited and signed,
**So that** sensitive content can't be accessed indefinitely.

## Acceptance Criteria

### AC1: Testimonial Downloads
- [ ] 24-hour signed URL expiration
- [ ] Cryptographic signature prevents tampering
- [ ] Log access for audit

### AC2: Voice Recording Playback
- [ ] 1-hour expiration
- [ ] Include client_id validation in signature

### AC3: Expired URL Handling
- [ ] 403 Forbidden with "Link expired" message

### AC4: Tamper Detection
- [ ] Invalid signature = 403 Forbidden
- [ ] Log as security event

### AC5: Share Sheet URLs
- [ ] 10-minute validity
- [ ] Prevents forwarded link abuse

## Reverse Engineering Finding

R2 assets need time-limited URLs - perpetual links are security risk.
