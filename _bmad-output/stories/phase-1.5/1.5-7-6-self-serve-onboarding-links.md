# Story 1.5-7-6: Self-Serve Client Onboarding Links

**Epic:** 1.5-7 - Agency Owner Dashboard
**Priority:** P0
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As an** agency owner,
**I want** to generate self-serve onboarding links for clients,
**So that** clients can start BrandDNA without me babysitting.

## Acceptance Criteria

### AC1: Link Generation
- [ ] Unique single-use URL
- [ ] 32-byte crypto-random token (base64url encoded)
- [ ] NOT sequential or guessable

### AC2: Client Flow
- [ ] Branded welcome: "[Agency Name] Brand Discovery"
- [ ] Create account and begin BrandDNA
- [ ] Auto-link to agency

### AC3: Pending Invites List
- [ ] Created date, Status (unused/used), Client name
- [ ] Expire/delete unused links

## Security Note

Security Audit: Crypto-random tokens prevent enumeration.

## Focus Group Finding

Marcus Chen needs clients to self-serve without blocking on availability.
