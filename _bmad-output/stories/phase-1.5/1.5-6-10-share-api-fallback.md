# Story 1.5-6-10: Share API Fallback

**Epic:** 1.5-6 - Mobile Review & Native Publish Flow
**Priority:** P0
**Status:** review
**Effort:** 3-4 hours
**Created:** 2025-12-30

---

## User Story

**As a** user on desktop or unsupported browser,
**I want** a fallback when native share sheet is unavailable,
**So that** I can still easily post to platforms.

## Acceptance Criteria

### AC1: Fallback Modal
- [ ] If `navigator.share()` unsupported:
  - "Copy Caption" button
  - Platform icon opens platform in new tab
  - Toast: "Caption copied! Paste in LinkedIn"

### AC2: Feature Detection
- [ ] Check `navigator.share` and `navigator.canShare`
- [ ] Conditionally render native or fallback UI

### AC3: Silent Failure Handling
- [ ] 3-second timeout triggers fallback
- [ ] Log error with device/browser info
- [ ] Show fallback UI on timeout

## Pre-mortem Finding

Share failures were silent - users tapped "Share" and nothing happened.

## Reverse Engineering Finding

Safari desktop doesn't fully support Web Share API.
