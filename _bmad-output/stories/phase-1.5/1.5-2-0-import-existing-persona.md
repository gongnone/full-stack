## User Story

**As a** user,
**I want** to import an existing audience persona from another tool (PDF, Notion, Google Doc),
**So that** I don't have to rebuild what I already know about my audience.

## Acceptance Criteria

### AC1: Path Selection
- [ ] ButtonChoice: "Start Fresh" or "Import Existing"

### AC2: Import Interface
- [ ] Upload: PDF, DOCX, TXT, or paste text
- [ ] Accept common persona formats (HubSpot, Notion templates)

### AC3: AI Extraction
- [ ] Workers AI extracts demographics, psychographics, content preferences
- [ ] Pre-populate PersonaCard component

### AC4: Review and Edit
- [ ] Can edit pre-populated fields
- [ ] Agent asks clarifying questions for missing fields only
- [ ] Skip Stories 2.1-2.4, proceed to Story 2.5
