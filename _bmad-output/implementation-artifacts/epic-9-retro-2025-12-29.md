## Challenges

### 1. TypeScript Safety Cascade

Story 9-8 was originally scoped as "replace `as any` casts" - but it cascaded significantly:

| Phase | Scope | Impact |
|-------|-------|--------|
| Initial Story 9-8 | ~15 `as any` casts | Completed 2025-12-28 |
| Remediation R-1 | 35+ `any` types discovered | 4-6 hours |
| Cascading R-1b | 58 frontend TypeScript errors | Additional 1 hour |

**Lesson:** Type safety fixes cascade. Fixing backend types correctly reveals frontend type mismatches that were quietly wrong.

### 2. Integration Test Infrastructure

The Miniflare-based integration tests fail in GitHub Actions CI:

```
AssertionError: false == true
❯ ProxyStubHandler.#parseSyncResponse miniflare/dist/src/index.js:51577:38
❯ _Miniflare.#getProxy miniflare/dist/src/index.js:62820:34
```

**Root Cause:** Miniflare's D1 proxy doesn't initialize properly in Ubuntu CI environment.

**Impact:** P1 Integration Tests fail in CI, though they pass locally.

**Solution:** Added TD-1 to technical debt backlog - migrate to `@cloudflare/vitest-pool-workers`.

### 3. Placeholder Integration Tests

Story 9-1's code review discovered an integration test that was literally:
```typescript
expect(true).toBe(true); // Placeholder - passes but tests nothing
```

**Lesson:** Code reviews must verify test *assertions*, not just that tests exist.

## Lessons Learned

### 1. The Dev-Story + Code-Review Pipeline Works

**Observation:** 19 issues caught across 8 stories, including 2 critical bugs.

**Pattern:** First pass gets functionality working, code review hardens it for production.

**Recommendation:** Continue mandatory adversarial code reviews for all stories.

### 2. Type Safety Debt Compounds

**Observation:** R-1 (35 `any` types) triggered R-1b (58 frontend errors).

**Root Cause:** When backend types are loose (`any`), frontend code builds incorrect assumptions.

**Recommendation:** Implement TD-2 (ESLint rule) to catch `any` types during development.

### 3. Integration Tests Need Real Infrastructure

**Observation:** Miniflare works locally but fails in CI.

**Root Cause:** Platform-specific native module differences between macOS and Ubuntu.

**Recommendation:** Implement TD-1 (migrate to `@cloudflare/vitest-pool-workers`) for CI-stable testing.

### 4. Remediation Sprints Are Effective

**Observation:** 7 remediation items completed in single session after deployment failure.

**Pattern:** Focused remediation sprints with clear priorities (P0 > HIGH > MEDIUM > LOW) are efficient.

**Recommendation:** Run remediation sprints immediately when deployment blockers are discovered.
