# Story 1.5-6-8: Native Share Sheet Trigger

**Epic:** 1.5-6 - Mobile Review & Native Publish Flow
**Priority:** P0
**Status:** review
**Effort:** 4-6 hours
**Created:** 2025-12-30

---

## User Story

**As a** user,
**I want** to share content via the native OS share sheet,
**So that** I can open the target platform app directly.

## Acceptance Criteria

### AC1: Share Trigger
- [ ] Trigger in < 500ms (NFR-1.5-P5)
- [ ] Use `navigator.share()` Web Share API
- [ ] Include media file from R2 signed URL (if applicable)

### AC2: Platform Opening
- [ ] Target app opens with content pre-loaded
- [ ] Can add native features (trending audio, stickers)
